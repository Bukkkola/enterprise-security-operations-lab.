# Enterprise Security Operations Lab

## Project Overview

This project simulates an enterprise Security Operations Center (SOC) environment using Microsoft Defender XDR and Microsoft Sentinel. The objective is to demonstrate endpoint protection, threat detection, incident investigation, and security monitoring through hands-on implementation and documentation.
## Project Objectives

- Build a Microsoft Defender XDR and Sentinel environment.
- Collect and analyse security telemetry.
- Simulate common cyber attacks.
- Perform threat hunting using KQL.
- Investigate and respond to security incidents.
- Document the complete implementation.

## Technology Stack

| Layer | Component | Purpose |
|--------|-----------|---------|
| Identity | Microsoft Entra ID | Identity and access management |
| Endpoint Security | Microsoft Defender XDR | Protects endpoints and correlates security events |
| SIEM/SOAR | Microsoft Sentinel | Threat detection, investigation, incident response, and automation |
| Data Collection | Log Analytics Workspace | Collects and stores security telemetry |
| Endpoint | Windows 11 VM | Windows endpoint used for attack simulations |
| Endpoint | Ubuntu VM | Linux endpoint used for log collection and monitoring |
